# Noonpost V0.7 Spec — 基调校准 · tone-rebalance

> **版本**：V1.0 初稿  
> **日期**：2026-04-15  
> **作者**：子敬（鲁肃）  
> **状态**：待 Litch + Root 评审  
> **前置版本**：V0.6b mission-bag-rewire（已合并）

## 一、版本目标

**一句话**：让聆从"在求生"变成"在探索"——信件读起来有发现感、有美感、有好奇心，而不是一路恐惧和膻味。

### Goals

1. 聆的信件基调从"苦旅求生"转向"好奇探索"，保留真实的艰辛但增加发现的惊喜
2. 节点圣经增加"发现层"（discoveries），让 LLM 有"值得好奇的素材"可写
3. 6 个旧节点完成完整节点圣经精修，统一走新 prompt 路径
4. 信件标题不再重复
5. 信件中有风景描写，不只是近景物件

### Non-goals

1. 不做风土囊替换升级机制（V0.6b 已知 non-goal）
2. 不做图片生成改进（独立版本）
3. 不做"主人喜好"个性化系统（后续版本方向，V0.7 不做）
4. 不改信件长度、结构、采样规则（当前的 letter_sampling_rules.yaml 是对的）
5. 不改引擎架构（V0.7 是纯数据层 + prompt 层改动）

## 二、问题诊断

V0.6b 验收中 Litch 发现 7 个问题，归为 3 层根因：

### 第一层：聆的人格基调偏差（F4，最高优先级）

**现象**：聆时不时害怕、心跳、觉得别人有恶意。整体感觉是"玩家在虐待聆流放"而不是"聆在好奇地探索世界"。

**根因**：

1. **SYSTEM_PROMPT 的人格定义缺少"好奇心"的显式权重**。当前定义了"用鼻子和耳朵认识世界""贪吃""不会说漂亮话"，但没有写"对没见过的东西特别好奇""好奇心比害怕大一点"。traveler.yaml 里的 `what_emerges_naturally` 把好奇心归为"自然涌现"——但实际上 LLM 不会自然涌现，它需要显式引导。

2. **journey_arc_modifier 的中段 60% 旅程情绪偏消极**。20-50% 是"疲惫"，50-80% 是"紧张"。LLM 拿到这些偏置词，写出来的信自然充满疲惫和紧张。

3. **节点圣经和旧 bible 的素材本身偏负面**（详见第二层）。

### 第二层：节点感官失衡 + 缺少发现素材（F2/F3/F5）

**现象**：酪浆和羊气味贯穿全程，早期信件血腥味重，缺少风景描述。

**根因**：

1. **旧节点（6 个）没有节点圣经**，只有一段 bible 文本。这些文本的感官描写集中在负面气味（膻、酸、粪），缺少正面视觉（风景、天空、建筑之美）和正面味觉（好吃的东西）。

2. **已有节点圣经（3 个）的素材也偏负面**。以河西走廊为例：
   - localProducts 6 项：酸马奶（腥气）、风干羊肉（膻味浓重）、干奶酪（硬如石头）、沙枣（入口干涩）、红柳筐（涩苦）、骆驼毛（粗如麻绳）。正面描写 ≈ 0。
   - bodyFeelHooks 8 个：风沙打脸、冷得发抖、嘴唇干裂、耳朵不停转动、鼻腔吸气微痛、脚垫烫、骆驼喷气熏眼睛、远处有水的味道。正面 : 负面 = 1:7。
   - nature 里写了"胡杨树皮裂开，渗出琥珀色树脂（胡杨泪）"——这是一个很好的发现素材，但它埋在 nature 字段里，不会被 bodyFeelHooks 或 sceneAnchors 主动采样。

3. **缺少"发现层"**。节点圣经的结构是"世界事实 + 聆的身体感受"，但缺少"聆可能发现的有趣的、美的、和中土不同的东西"。Litch 的 demo 信里的"胡杨泪""沙枣甜甜的""岩画"都属于这一层——它们不是身体感受，而是认知惊喜。

### 第三层：信件去重不足（F1）

**现象**："大月氏，到了"出现 4 次。

**根因**：`formatRecentJournal` 只传 summary，不传 title。LLM 不知道之前用过什么标题。

## 三、方案设计

### 改动 A：SYSTEM_PROMPT 人格校准

在"你是谁"部分增加两条：

```
你是谁：
- 用鼻子和耳朵认识世界。夜里或危险时，常先听到、闻到；白天开阔的时候，也会先看见。
- 对没见过的东西特别好奇。新的建筑、新的食物、新的风景、没闻过的味道，都会凑过去看很久。  ← 新增
- 贪吃。遇到食物一定凑过去，吃到好吃的会忘记害怕。
- 不会说漂亮话。不抒情、不总结、不给建议。只描述经历了什么。
- 偶尔冒出一句好玩的话——不是讲笑话，是用自己的方式理解世界时自然产生的歪打正着。
- 害怕的时候会害怕，但好奇心总是比害怕大一点。看到危险的东西，先躲，然后偷偷回头看。  ← 新增
```

在"写信规则"部分增加发现弧和远景引导：

```
写信规则：
- 短句到中短句，具体，感官化。像小动物写日记，不是散文。
- 用动作和气味代替形容词。多写闻到的、听到的、看到的、尝到的。
- 每封信至少写一个你能看见的远处画面——一段山、一条河、一片天、一片沙丘。先写远处看到的，再写近处闻到的。  ← 修改
- 看到没见过的东西，写下来。不用解释它是什么，写你怎么发现它的、它摸起来/闻起来/尝起来什么样。  ← 新增
- 信件长度会在下方指定。
- 每封信最多一句轻微情绪，不要整封都在抒情。
- 禁用词：令我、使我、不禁、仿佛、宛如、遂、竟
```

同步更新 `buildAlwaysInject` 中的角色基准压缩：
```
'聆，耳廓狐，用鼻子认识世界，对没见过的东西特别好奇，贪吃，不会说漂亮话。'
```

### 改动 B：journey_arc_modifier 重写

```typescript
if (pct < 0.2) lines.push('刚出发，什么都新鲜，什么都想闻。');
else if (pct < 0.5) lines.push('走了一段了，开始认得路上的东西。偶尔累，但看到没见过的东西就忘了。');
else if (pct < 0.8) lines.push('走了很远了，身体习惯了。眼睛比刚出发时看得更仔细，能看到以前看不到的东西。');
else lines.push('快到了。走了这么远，觉得自己变大了一点。');
```

同步更新 `buildProgressFallback` 中的 journey stage 文案：
```typescript
if (pct > 0.8) return '路快到头了，想看的东西反而更多了。';
if (pct > 0.5) return '走了很远了，路上的东西开始变得不一样。';
return '继续往前走，鼻子先行。';
```

**核心变化**：把"疲惫/紧张"替换为"认得/看得更仔细/变大了一点"。保留身体累的真实感，但情绪基调从"求生"转向"成长"。

### 改动 C：节点圣经增加 discoveries 字段

在 NODE_BIBLE_STANDARD.md 的 views 层新增 `discoveries` 字段定义：

```yaml
views:
  letter:
    bodyFeelHooks: [...]      # 身体感受（已有）
    silentEncounters: [...]   # 沉默遭遇（已有）
    npcEventHooks: [...]      # NPC 交互（已有）
    discoveries: [...]        # 发现层（新增）
  sketch:
    sceneDescription: "..."   # 图像描写（已有）
```

**discoveries 字段定义**：

```yaml
discoveries:
  - id: "hutong_tears"
    type: visual          # visual / tactile / gustatory / auditory / olfactory
    what: "胡杨树皮裂开，渗出琥珀色的树脂"
    how_found: "路过一棵胡杨，看到树干上有亮晶晶的东西，凑过去闻，有淡淡的甜味"
    surprise: "原来树也会流眼泪，但这个眼泪是甜的"
    # surprise 是聆的认知惊喜——用自己的方式理解这个新东西
```

每个 discovery 包含：
- **what**：发现了什么（世界事实）
- **how_found**：怎么发现的（聆的行为弧：看见 → 好奇 → 凑过去）
- **surprise**：聆的认知惊喜（用自己的方式理解，不是百科解释）

**每个节点至少 4 个 discoveries**，覆盖不同感官类型。

### 改动 D：localProducts 正负平衡重写

对所有节点的 localProducts，在保留负面感官描写的同时，增加正面感官描写。

以河西走廊为例：

```yaml
localProducts: |
  酸马奶（湩），装在缝制粗糙的皮囊里，发酵酸味混着皮革腥气。但喝惯了以后，能尝到底下一层淡淡的奶甜。
  风干羊肉条，表面结着白色盐霜，咬下去坚硬，膻味浓重。嚼久了会出肉汁，咸的。
  沙枣，表面银白粉末，入口干涩，嚼后微甜，甜得像蜜枣。是路上最好吃的东西。
  干奶酪（酪蛋子），硬如石头，含化许久才尝到浓郁奶酸。含着走路，嘴里不那么干了。
  红柳枝烤肉串，肉串在红柳枝上烤得滋滋响，油滴在火上冒烟，闻着比吃着香。
  骆驼毛，从驼颈剪下，粗如麻绳，但捂在身上暖和。
```

**原则**：不删负面（真实），但每个物产至少有一个正面感官锚点（也真实）。让 LLM 有正面素材可选。

### 改动 E：bodyFeelHooks 正负平衡

对已有 3 个节点圣经，每个补 3-4 个正面 bodyFeelHook。目标：正面 : 负面 ≥ 1:2。

河西走廊示例新增：
```yaml
- trigger: { timeOfDay: day }
  feel: "翻过一道沙梁，突然看见远处祁连山的雪线，白得发亮，盯着看了很久"
- trigger: { waterChance: low }
  feel: "绿洲的水井旁长着一丛芦苇，风吹过来沙沙响，踩在湿泥上凉凉的，舒服"
- trigger: { timeOfDay: night }
  feel: "夜里抬头，星星多得像撒了一地沙子，银河从头顶横过去"
- trigger: { windLevel: low }
  feel: "风停了，沙漠安静得能听到自己的心跳。远处沙丘的轮廓像一条条金色的波浪"
```

### 改动 F：6 个旧节点完整节点圣经精修

**这是 V0.7 工作量最大的部分。**

6 个旧节点（长安、陇西、匈奴王庭、玉门关、龟兹、大宛）目前只有一段 bible 文本，走 legacy prompt 路径。需要按 NODE_BIBLE_STANDARD.md 的标准做完整精修：10 要素 + views（bodyFeelHooks / silentEncounters / npcEventHooks / discoveries / sceneAnchors / sketch）+ objectPool + constraints。

精修完成后，这 6 个节点也走新 prompt 路径（buildSlotContext），不再走 buildLegacyContext。

**精修顺序建议**（按 Litch 验收中暴露问题的严重程度排序）：

| 优先级 | 节点 | 建议感官主轴 | 理由 |
|--------|------|-------------|------|
| P0 | 匈奴王庭 | 膻（但要有暖） | 验收中问题最多的节点，stayDuration 4-8 拍，信件重复感最强 |
| P0 | 陇西 | 凉 | 旅程早期节点，"血腥味"的主要来源 |
| P1 | 玉门关 | 空 | 出关节点，叙事转折点 |
| P1 | 龟兹 | 彩（或响） | 西域第一个繁华城市，应该是旅程中最大的"发现惊喜" |
| P2 | 大宛 | 醇 | 汗血马、葡萄酒、希腊遗风 |
| P2 | 长安 | 稠 | 出发点，信件数量少（stayDuration 短），优先级最低 |

**每个节点精修流程**：按 NODE_BIBLE_STANDARD.md 的四阶段流程（调研 → 初稿 → 审阅 → 定稿），子敬负责。

### 改动 G：信件标题去重

修改 `formatRecentJournal`，同时传入 title 和 summary：

```typescript
function formatRecentJournal(input: LetterGenerationInput): string {
  if (input.recentJournal.length === 0) return '（尚无记录）';
  return input.recentJournal
    .map((entry) => `- 标题：${entry.title ?? '无'} | 摘要：${entry.summary}`)
    .join('\n');
}
```

同时在 SYSTEM_PROMPT 的标题规则中增加：
```
- 标题不可与最近 5 封信的标题相同或高度相似。
```

**前置条件**：recentJournal 的数据结构中需要包含 title 字段。需要检查 journal 的存储和读取逻辑是否已经保存了 title。

### 改动 H：prompts.ts 增加 discoveries 采样

在 `buildSlotContext` 中新增 discoveries 采样槽位：

```typescript
// Slot 6: discovery_anchor (可选, ~40%)
const discovery = pickDiscovery(bible, beatSeed5);
if (discovery) {
  sections.push(`【路上发现的新东西】\n${discovery}`);
}
```

`pickDiscovery` 函数从 `bible.views.letter.discoveries` 中随机选一个，注入 what + how_found + surprise。

**采样概率 ~40%**：不是每封信都有发现，但比 history_anchor（30%）更频繁。发现感是这个产品的核心体验。

## 六、验收口径卡

**核心目标**：读完一趟旅程的信，感觉是"聆在好奇地探索世界"，不是"聆在被流放受苦"。

**3 个必须通过的真实用例**：
1. 跑一趟完整旅程（16 拍），信件中至少有 5 封包含"发现新东西"的描写（看到没见过的、尝到好吃的、听到新的声音）
2. 匈奴王庭停留 4-8 拍，信件标题不重复，内容不全是酪浆和膻味
3. 河西走廊的信件中至少有 1 封提到远处的风景（祁连山、沙丘轮廓、星空）

**2 个不能破坏的旧行为**：
1. 风土囊仍然能填上（V0.6b 的改动不能被破坏）
2. 物件图鉴正常工作，物件的 provenance 校验不变

**1 个最容易被 agent "做假"的点**：
- discoveries 注入后，LLM 可能会把 discovery 的 surprise 字段原封不动抄进信件，变成"模板感"。验收时要看信件是否自然融入了发现，而不是机械地"我发现了 X，它摸起来 Y，我觉得 Z"。

**失败时应该怎么表现**：
- 如果基调没改善：信件仍然充满恐惧和膻味，说明 SYSTEM_PROMPT 的权重不够或节点圣经素材仍然偏负面
- 如果发现感太假：每封信都有一个"发现"但读起来像百科词条，说明 discoveries 的 surprise 字段写得太理性

**Litch 最终验收方式**：
- 本地跑 3 趟旅程，读信，凭体感判断"这是不是一只好奇的小狐狸在探索世界"

## 七、开放问题

1. **匈奴王庭的 stayDuration [4, 8] 是否需要调整？** 这是信件重复感最强的节点。可选方案：缩短到 [3, 5]，或在 prompt 中加入"在同一个地方待久了，开始注意到之前没注意到的细节"的引导。

2. **discoveries 的采样概率 40% 是否合适？** 太高会让每封信都有"发现"，失去惊喜感；太低又回到老问题。可能需要模拟器调参。

3. **旧节点精修的审阅流程是否简化？** 6 个节点如果每个都走"Litch + Root + Vox 三方审阅"，周期会很长。建议：P0 节点（匈奴王庭、陇西）走完整审阅，P1/P2 节点子敬自审 + Litch 抽检。

4. **是否需要更新 traveler.yaml？** 当前 `what_emerges_naturally` 把好奇心归为"自然涌现"，但 V0.7 的改动是把好奇心显式写入 prompt。traveler.yaml 需要同步更新，把好奇心从"自然涌现"移到 `core_traits`。

## 八、风险评估

### 技术风险
- **旧节点切换新路径时可能有类型不匹配**：新精修的 YAML 需要严格符合 NodeBible 类型定义，否则 tsc 报错或运行时 crash
- **discoveries 采样和 sceneAnchors 采样可能冲突**：同一封信如果既有 scene_anchor 又有 discovery，prompt 可能过长或信息重复

### 产品风险
- **基调校准过度**：如果正面感官加太多，聆可能变成"一切都好棒"的旅游博主，失去"小动物在真实世界中"的质感。需要保持正负平衡，不是全正面。
- **6 个节点精修周期长**：如果每个节点都精修到河西走廊的质量，可能需要 2-3 天。建议分批交付。

## 九、Litch Demo 信分析

Litch 写的 demo 信（河西走廊）展示了理想的信件应该是什么样的：

```
我到河西走廊啦！一路走来，茫茫大漠，看到了祁连雪山，还有骆驼、黄羊，
两边的胡杨树上挂着眼泪，我好奇问了问匈奴游骑，说这是胡杨泪——就是琥珀色的树脂，
非常有趣，给主人随信附上。

吃到了酸马奶、还有红柳大串和风干羊肉条、沙枣。马奶和羊肉条还是太膻了，
但是沙枣很不错！！甜甜的。

遇到一位匈奴牧马少年，主动赶着三匹瘦马，在沙丘与天际的交界处走。

比较困难的是白天不敢生火、没有正式市集，而且晚上很冷。

另外看到了岩画。我准备画下来给主人看！
```

**关键特质对照**：

| 特质 | Demo 信 | 当前系统 | V0.7 如何解决 |
|------|---------|---------|--------------|
| 发现弧（看见→好奇→了解→惊喜） | "胡杨泪——非常有趣" | 无 | 改动 C: discoveries 字段 |
| 有判断力（好吃/难吃） | "沙枣很不错！！甜甜的" | 中性描述 | 改动 A: 人格校准 + 改动 D: localProducts 正负平衡 |
| 远景→近景→人的叙事节奏 | 祁连雪山→食物→牧马少年 | 从近景物件开始 | 改动 A: "先写远处看到的" |
| 聆的主动性 | "我好奇问了问""我准备画下来" | 被动经历 | 改动 A: "好奇心比害怕大一点" |
| 困难是真实的但不压倒性 | "比较困难的是...但是..." | 困难占主导 | 改动 B: journey_arc 重写 |
